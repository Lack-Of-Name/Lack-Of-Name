### About

I am Lyren, a developer focused on cross platform mobile and mapping tools. I build reliable, offline first navigation products with React Native, Expo, and TypeScript. Based in UTC+10, open to remote roles and contract work where map accuracy, performance, and field usability matter.

Current focus is CadNav2, a production navigation app for Android and iOS with offline packs, MGRS grid, and sensor driven compass.

**CadNav2** - Cross platform navigation and mapping for field use

Offline first, grid accurate, built with React Native and Expo. Single codebase for Android and iOS with MapLibre GL and MapTiler.

- Real time GPS tracking with heading and north up, background location support
- Offline map packs with local cache and progress management
- MGRS entry and overlay, 100m and 1m precision
- Routes and checkpoints, add by tap or by bearing and distance
- Compass with World Magnetic Model correction, no network required
- QR sharing for routes and checkpoints, light and dark themes

Stack: React Native 0.81, Expo 54, TypeScript 5.9, MapLibre GL, MapTiler, Turf.js, AsyncStorage
