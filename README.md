## Right now

All my energy is on **CadNav2**, a navigation app for Android and iOS for field use. Offline first, grid accurate, one codebase.

What it does:
* Live GPS with heading, north up, and background tracking
* Offline map packs with local cache
* MGRS overlay and entry, 100m and 1m precision
* Routes and checkpoints by tap, or by bearing and distance
* Compass with offline magnetic correction
* QR sharing for routes and checkpoints, light and dark themes

Stack: React Native 0.81, Expo 54, TypeScript 5.9, MapLibre GL, MapTiler, Turf.js, AsyncStorage

[View the repo](https://github.com/Lack-Of-Name/CadNav2)
